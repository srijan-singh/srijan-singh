## About

I’m a Software Engineer at IBM working on Data Lineage, building systems that help organizations understand where data comes from, how it moves, and how it transforms across complex data environments.

My work spans backend engineering, data processing, and distributed systems, with a focus on designing reliable and scalable solutions across technologies such as Java, Spring Boot, Neo4j, Kubernetes, and cloud data platforms. I work across the full engineering lifecycle—from understanding ambiguous problems and designing solutions to implementation, testing, debugging, and production readiness.

More recently, I’ve been exploring how AI agents and engineering skills can improve the software development lifecycle. I’m particularly interested in turning domain knowledge and engineering practices into reusable workflows that help teams build, test, and deliver software more efficiently.

Outside my core role, I contribute to open source, work on side projects, and explore ideas around developer productivity, AI-assisted engineering, and technical innovation.

Always interested in solving difficult problems, learning how systems work under the hood, and building things that make engineering better.
